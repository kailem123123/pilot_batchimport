# pilot_batchimport
# BatchImportPlugin for Ascon Pilot-BIM / Pilot-ICE

![Pilot-BIM](https://img.shields.io/badge/Platform-Pilot--BIM%20%7C%20Pilot--ICE-blue)
![.NET Framework](https://img.shields.io/badge/.NET%20Framework-4.7.2%20%7C%204.8-orange)
![License](https://img.shields.io/badge/License-MIT-green)

Универсальный модуль расширения (плагин) контекстного меню для клиентских приложений экосистемы **Ascon Pilot** (BIM/ICE/ECM/Enterprise). Предназначен для автоматизации рутинного переноса больших массивов проектных данных в систему.

Плагин добавляет в интерфейс Обозревателя документов две независимые команды, позволяющие пакетно загружать локальные файлы, автоматически генерируя под каждый файл индивидуальную карточку с заполнением реквизитов и привязкой исходников.

---

## 🚀 Основные возможности

* **Две раздельные команды импорта:** Индивидуальные кнопки для создания карточек типа `Документ` и `Письмо`.
* **Пакетная обработка:** Возможность одновременного выбора и загрузки любого количества файлов любых форматов (`.pdf`, `.dwg`, `.docx`, `.dxf` и др.).
* **Автоматическое связывание (Source Files):** Файлы физически создаются как дочерние контейнеры внутри карточек, а логическая связь `ObjectRelationType.SourceFiles` автоматически выводит их в правую боковую панель Pilot.
* **Умное именование:** Система анализирует метаданные типов на Pilot-Server и автоматически сопоставляет имя файла с доступными текстовыми атрибутами (`title`, `name`, `subject`, `summary`).
* **Транзакционность:** Изменения фиксируются через `_modifier.Apply()` на каждой итерации. В случае сбоя одной карточки транзакция безопасно откатывается через `_modifier.Clear()`, не засоряя базу данных.

## 🛠 Настройка среды разработки (Localhost)

Для сборки и интерактивной отладки расширения выполните следующие шаги:

1. **Тип проекта:** Создайте проект типа **Class Library (.NET Framework)** с целевой платформой **.NET Framework 4.7.2** или выше.
2. **Имя сборки:** В свойствах проекта (*Project -> Properties -> Application*) в поле **Assembly Name** допишите к названию расширение `.ext2` (например, `PilotSimpleImportPlugin.ext2`)[cite: 1, 4].
3. **Зависимости:** Подключите через NuGet пакет `Ascon.Pilot.SDK`[cite: 1, 4], а также добавьте ссылки (References) на системные сборки `System.ComponentModel.Composition` и `System.Windows.Forms`[cite: 1, 4].
